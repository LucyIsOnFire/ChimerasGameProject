### GENERAL RULES ###
0. PascalCase for everything! (with some exceptions)
1. public before private
2. Public properties are capitalized, private are not
3. variables created by a method start with an underscore
4. attributes are added one line above the element they are modifying, like [Export] or [Signal]
5. parameters for methods do not start with an underscore, and the first letter is lowercase
6. Constants and enum members are all capitals, with underscores as spaces
7. Do Summaries of as many methods as possible, especially if the method is complex
8. Add Descriptions and Summaries whenever and wherever possible for any abstract method or code
9. Delegate variables end with "Delegate<Type>", either being an Action, Function, or Predicate
10. Double Space before and after methods

Summary:
/*
<summary>
Summary goes here
</summary
*/
